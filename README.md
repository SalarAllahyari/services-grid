# Services Grid

A simple services landing page built with HTML and CSS, focusing on CSS Grid layout.

## About the Project

This project was created as a front-end practice exercise to improve my understanding of CSS Grid.

It includes five service cards arranged in a three-column grid layout, with one featured card spanning two columns.

## Built With

- HTML5
- CSS3
- CSS Grid

## Features

- Three-column grid layout
- Featured card spanning two columns
- Styled service cards
- Clean and simple design

## What I Learned

- Using `display: grid`
- Creating columns with `grid-template-columns`
- Controlling spacing with `gap`
- Spanning columns with `grid-column`
